# FlClashTier（简体中文）

</div>

本文档与 [README.md](README.md) 相同（主 README 即为中文版本）。

FlClashTier = FlClash + ZeroTier Core 双网络出口：单个 Android VPN 内同时运行
Mihomo（代理）与 ZeroTier（虚拟组网），并支持**私有 Planet（自建 ZeroTier 根服务器）**。

最新特性：**四种路由模式（单选）**——纯 Clash / 纯 ZeroTier / 共存互不影响（默认）/
Clash 走 ZeroTier（通过 ZT 内网连接部署在局域网里的 Clash 节点）。
详见 [README.md](README.md)。
